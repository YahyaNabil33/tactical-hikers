# Tactical Hikers — Homepage Concept

A homepage design for **Tactical Hikers**, a tactical and outdoor gear shop with four branches in Jordan. Built with plain HTML and CSS, with no JavaScript and no frameworks.

> **Concept demo.** This is a design proposal, not the store's official website. There is no live shop: cart, search and account are not connected.

## Features

- **Responsive layout** for desktop and mobile, with a slide-in phone menu
- **Category panels** that expand on hover
- **Featured products** with colour and size pickers
- **Search bar** that opens with the HTML `popover` attribute, with no JavaScript
- **Customer photo slider** using CSS scroll snapping
- **Scroll-in animations** with CSS scroll-driven animations, disabled for visitors who prefer reduced motion
- **Accessibility:** skip link, keyboard focus styles, ARIA labels, semantic landmarks
- **Branch footer** with phone numbers, opening hours and map links

## Tech

HTML5, CSS3 (custom properties, grid, flexbox, `popover`, `:target`, scroll snap, scroll-driven animations), Google Fonts (Oswald, Cairo).

## View it

Open `index.html` in a browser. Fonts load from Google Fonts, so go online for the intended typography.

## Browser notes

- The slider's position bar and the scroll-in effects work in Chrome, Edge and Safari. Firefox shows the content without them.
